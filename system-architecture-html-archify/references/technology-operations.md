# 技术选型、部署与运维规范

主页面 `technology-operations` 区域从统一数据生成响应式表格。

- 技术选型：名称、版本、用途、理由、备选、约束、模块、状态、来源。
- 部署设计：环境、模式、拓扑、网络/数据边界、配置密钥、发布、弹性、恢复、状态、来源。
- 运维设计：责任、指标日志 Trace、SLI/SLO、告警、事件响应、变更、备份灾备、容量成本、安全和 Runbook。

未知版本、SLO、RTO、RPO、保留期、责任人和预算阈值必须进入待确认，不猜测数字。逻辑架构与物理部署分别生成 Archify `architecture` 图。

表格支持筛选、键盘、Hash 和详情抽屉；状态使用文字 Badge；窄屏滚动仅发生在表格容器。
